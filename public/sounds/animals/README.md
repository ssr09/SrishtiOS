# Animal Sounds

Animal sound files are loaded by `AnimalSounds.tsx` using the animal id:

`/sounds/animals/{id}.mp3`

Most existing files predate this note. The following files were added from
freely licensed Wikimedia Commons media and trimmed to short app-friendly clips.
