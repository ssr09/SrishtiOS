# Project Goals

## Primary Goal

Create an engaging, educational app suite for Srishti (2.5 years old) that supports daily routines, learning, and play.

## Design Principles

### 1. Toddler-First UX
- **Large touch targets**: Minimum 140px buttons, prefer 180px for primary actions
- **Immediate feedback**: Every tap produces visual/audio response
- **No failure states**: All actions result in positive outcomes
- **Visual over text**: Rely on emojis, colors, animations (non-literate users)

### 2. Parent-Friendly
- **Hidden settings**: Long-press (1.5s) to access ParentPanel
- **Customizable content**: Add/remove foods, toys, timer presets
- **Data portability**: Export/import settings and progress
- **No ads, no tracking**: Privacy-first for child data

### 3. Offline-First
- **No backend required**: All data in localStorage
- **Works without internet**: After initial load, fully functional offline
- **Fast loading**: Optimized bundle, no external API calls

### 4. Mobile-First
- **Touch optimized**: No hover-dependent interactions
- **Responsive**: Works on phones, tablets, and desktops
- **PWA-ready**: Can be added to home screen

## Success Metrics

Since this is a personal project, success is measured by:

1. **Engagement**: Does Srishti enjoy using it?
2. **Learning**: Is she recognizing colors, shapes, numbers?
3. **Routine support**: Does it help with daily routines?
4. **Parent utility**: Is it easy for parents to customize?

## Non-Goals

- Monetization (no ads, no in-app purchases)
- Social features (no sharing, no multiplayer)
- Complex gamification (no levels, XP systems)
- Backend/accounts (keeping it simple and private)
